# 统一指令定义与效果绑定验收

本轮把完整资料构建、事实依赖交付、已确认效果的参数绑定和生成检查接入现有 Registry/Core。全部 Registry／手册联合条目进入同一入口；已核对范围内的参数排列和状态检查由 Core 完成。型号采用公共定义及差异存储，核对结论仍绑定具体形式、CPU 和来源。

基线为 `0b29748` 加本轮未提交修改。环境为 Windows AMD64、Python 3.13.14、pytest 9.1.1、Node 24.18.0，以及保存的 DeepSeek 预设。原始请求、规格、响应和结果在仓库外的本机私有目录；仓库保存合成案例和本报告。本轮未提交、推送、运行 GX Works2 编译或写入 PLC。

原生形式来自手册字面 Mnemonic 栏，不能从家族图标推导。32 个只有 D 形式的 FX3U 家族别名不再作为可调用指令，相应替代形式保留。D 表示输入／指令位宽，P 表示脉冲执行；结果宽度单独核对。MUL 的 16 位输入产生 32 位结果，占 2 字；DMUL 的 32 位输入产生 64 位结果，占 4 字。

用途审计为 **227 形式、631 槽位：27 verified、604 candidate、0 未解决；227 个形式用途证据齐全**。18 个候选位置由另一本指定官方手册的定义页补齐，回执列出实际手册与版本，不改写 signature 冻结记录。用途证据覆盖不等于解释或生成正确率，本轮没有批量 promotion。

## 交付、绑定与检查

任务视图按依赖选取，分别记录选择、打包、最终交付、预算遗漏和冲突。保持条件不同的公式不合并；其他 CPU／指令的同名 ID 不提供交付认证。来源单元保留原始位置，独立槽位保留自己的严格仲裁结果。章节查询恢复完整 Set data 表，格式归一化不改写语义。

Agent A 的 `operation_intent_claims` 保持候选状态。用户明确确认后，[instruction_binding](../../src/plc/instruction_binding.py) 匹配带类型表达式，构造 `OP <id>` 的原生参数。原生返回也接受同一检查：仅在唯一已确认效果、已核对定义、相同读值和既定输出／门控下重排参数，记录 `native_read_parameter_rebinding`。地址／数值变化、重复调用、候选依赖或明确锁定的错误完整调用不被猜测修复。

已确认输入状态的 NO／NC 绑定是单独的 Core 阶段，只处理既有触点及明确物理输入，不新增拓扑。已知决定性布尔值可以与未知输入组合；未知状态不自动成为正确状态。

67 个核对形式由通用表达式、有限位宽计算、条件结果、区域读写、移位重排、状态更新和资源契约描述。新增实例包括 MUL／DIV、INC／DEC、WAND／WOR／WXOR、NEG、XCH、ZCP 的 D/P 形式。检查涵盖完整结果区域、调用次数、使能、额外写入和执行序列。

除法采用向零截断及被除数符号的余数；除零、最小有符号数除以 −1 保持异常边界。自增、自减、取负按有限宽度回绕。XCH 的形式化子集要求 M8160 为关闭状态，且完整字区域不重叠；ZCP 使用手册规定的有效上界。P／电平执行及关闭保持来自明确公共规则，不能把纯计算保持推广到 IVCK 的通信动作。上述检查不代表原生编译、全部标志或实际硬件行为已验证。

此前 142 次初测／修复／难例、6 次 cache 检查和第一批全形式 196 次均保留，加最终 196 次共 **540 次真实请求**。旧 ADD 响应把 OP 写进 opcode、旧控制触点极性错误，以及首次全形式的两个 evaluator 误判均保留。缺少原生参数的旧响应不猜测恢复，引用格式及显式触点绑定已修复。两个误判分别来自共享输入的设备清单遗漏，以及已确认常闭接点的门控预期；已经修 evaluator 并离线重评，不冒充新增模型实测。

稳定协议、来源规则、型号能力、事实及范例放在动态规格之前，结构化键使用稳定顺序。计量读取供应商实际 hit／miss 或标准 cached 字段，缺失保持缺失，矛盾值不计入命中率；按输入 token 加权，不混入本地检索 cache。

## SQLite 旧索引检查与修复

原库 `integrity_check` 为 `ok`，外键违反为 0；10 个 manual、3,064 个 page artifact、4,714 个 chunk、7,324 个 table、4,714 个 embedding 均仍在库中。结构完整不代表派生语义正确。

旧索引把 ADD 指向教程页、DVIT 指向公共参数说明页。WSFL 只剩 D，IVCK 只剩 S2；TCMP 多出页边栏产生的 N，并有未闭合描述。结构化基本／应用手册仅索引 77 条，目录中实际有 232 条可归属记录。

构建器改为明确标题／目录祖先归属，指令格式章节优先于同名公共规则。从原生符号或 ST 签名绑定，设备表不新增操作数，不根据未标注行的物理顺序补用途。Data setting／跨页 Devices 的同页表格有界恢复接入同一文档解析器；新构建不再把派生摘要写进原文 chunk。

独立副本重建后有 **657 条主记录**：原生编程 220、定位 8、结构化基本／应用 232、应用函数 197。原 285 条保留 282，新增 375；3 条没有字面定义归属的旧记录 BK／FLDE／MODBUS 不继续作为主定义。276 条保留记录的指针、参数或摘要更新。

ADD 主指针恢复到 PDF 273，DVIT 到 176。WSFL 恢复 S/D/N1/N2，IVCK 恢复 S1/S2/D/N，TCMP 恢复 S1/S2/S3/S/D。ST 的 WSFL 顺序仍为 S/N1/N2/D；提取中缺少符号的用途保留 unknown，不借用原生顺序或批量提升事实。

独立副本完整性及外键检查通过，逐行比较确认 manuals、page_artifacts、tables、chunks、entity_index、FTS、embeddings 与来源库相等；4,714 个向量的已有内容身份与 chunk 身份不一致为 0。原库及历史 signature／operand 核验输入未覆盖；`--refresh-instruction-index-only` 要求独立输出。**本轮完成构建修复与副本验收，没有执行运行库替换或历史证据迁移。** 当前运行时用途及章节事实来自编译定义，原文继续从现有 SQLite 读取。
