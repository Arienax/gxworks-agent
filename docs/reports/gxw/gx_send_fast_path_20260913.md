# Web CSV 发送到 GX：隔离验收（2026-09-13）

> 历史记录。来源文档冻结于 `f2f1781a846c9f7073724b4cca485082d57f414c`；实验日期、样本和被测版本按正文记录。代码路径、命令和未完成事项描述当时环境。当前操作从[文档索引](../../README.md)进入。

验收对象为 Windows 上单独启动的 GX Works2 实例、新建并保存的 FX3U 简单梯形图工程。
测试调用绑定该实例的进程及窗口，并在每次导入前检查其仍打开测试文件；未操作用户原先打开的未命名工程，也未连接真实 PLC。
输入为 `LD X0 → OUT Y0 → END` 和 X0/Y0 两项注释，通过生产 Web 提案、审批、执行队列和 ImportService 执行。

## 实际测量

毫秒计时来自 ImportService 的单调时钟；不含用户阅读弹窗的时间，也不包含网络请求前的排队时间。

| 测量 | MAIN 导出 | 注释导出 | 程序导入 | 注释导入 | 含校验、记录与保存的总耗时 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原保护流程，首次运行 | 1.786 s | 5.650 s | 1.762 s | 1.603 s | 11.451 s |
| 快速发送，确认一次 | 不执行 | 不执行 | 1.763 s | 1.689 s | 3.807 s |
| 原保护流程，后续热态对照 | 1.739 s | 1.311 s | 1.772 s | 1.656 s | 7.348 s |

三次均成功导入程序、注释并保存。热态对照与快速发送均在 GX 已含相同目标程序及注释时执行；首次运行包含编辑器首次激活成本。快速发送相对热态对照减少约 3.54 秒（48%），相对首次运行减少约 7.64 秒（67%）。这是隔离小工程的观测，不是其他工程规模、机器或 GX 状态的时间保证。
