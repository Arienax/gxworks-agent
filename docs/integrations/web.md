# 本地 Web 工程工作台

安装和启动见[第一个工程](../guides/getting-started.md)。本页说明工作区、版本与日常操作；接口字段见 [HTTP 参考](http-api.md)。

## 工作区与版本

工作区保存工程索引、版本和已接受产物。任务、提案和暂存文件由应用状态目录管理，位置由 [integrations.web.__main__.main](../../src/integrations/web/__main__.py)的 `--state-dir` 与 [WorkspaceWriterLock](../../src/application/workspace.py)相关实现决定。模型设置独立存储，见[配置存储](../guides/model-settings.md#storage)。

同一工作区只保留一个写入服务。切换程序目录前停止旧服务；不要删除运行中服务的锁，也不要用多个 worker 或热重载并发执行 GX 操作。只读启动可检查旧工作区而不迁移文件。

项目页显示选定版本。分析形成待审规格，确认后生成候选；直接请求的程序通过保存事务后成为新版本。失败候选保留诊断但不会成为活动程序。历史版本的 IR、产物和规格快照保留原身份。

## 查看与导出

梯形图可按网络、地址或注释定位，并查看读取和写入引用。“本版变更”展示与父版本的实际差异。顶部导出菜单只列出该版本实际登记的文件；“刷新结果 / 重绘梯形图”从保存 IR 渲染，不调用模型。

交付摘要、交互记录和问题复现见[诊断与记录](../guides/diagnostics.md)。各类检查状态的含义见[生成交付](../architecture/generation-delivery.md)。

## 修改范围

在 Agent 输入区展开“修改范围”，可指定网络 ID、地址或两者。适用的 Ladder 编辑与 GX 读取在候选创建和保存时检查范围，结构修复继承原范围。不能确定间接或块指令影响范围时，使用明确的网络范围。

首次生成、FBD 和 ST 不提供这项 Ladder 范围约束。字段和规则由 [plc.change_scope](../../src/plc/change_scope.py)维护。

## 外部操作与测试

审批模式在“设置 → 常规 → 操作审批”中修改，规则见[审批策略](../architecture/approval-modes.md)。发送、回读、同步和真实 PLC 只读入口见 [GX Works2 指南](../guides/gxworks2.md)；结构化工程见 [FBD 指南](../guides/fbd.md)。

仿真页编辑输入、等待条件、断言及需求关联。保存产生新的测试方案，执行绑定选定程序和方案。波形回放使用保存的观测值，失败断言跳转到对应样本。后端种类与验证结果分别显示；测试关联由设计者建立，执行结果按实际记录展示。

## 任务恢复

刷新页面后恢复既有任务和事件，不重新提交生成。任务取消在安全检查点生效；已经开始的外部操作要按其实际结果核对。进程中断留下中断记录，重启不会自动重复导入。

操作员会话链接和模型凭据只供本机使用。会话、跨域与 Agent 访问规则见 [HTTP 参考](http-api.md)。外部 Agent 的安装流程从 [MCP 接入](onboarding.md)开始。
