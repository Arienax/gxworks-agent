# Third-party frontend dependencies

The dependency versions and integrity records are pinned in `web/package-lock.json`. Third-party packages retain their own license and copyright notices. When redistributing built assets, retain the applicable notices supplied with the installed packages.

The interface uses React, Radix UI, Lucide icons, Tailwind CSS, clsx, class-variance-authority and tailwind-merge. Build tooling includes Vite, TypeScript and openapi-typescript. Consult each installed package's license before redistributing a build.
